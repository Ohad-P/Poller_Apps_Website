# Poller Apps Brand

## Position

Poller Apps is an independent digital workshop for apps, games, useful tools, and experiments. It should feel personal and inventive without pretending to be a large agency.

Core line:

```text
Small tools. Carefully made.
```

## Visual Direction

The identity combines a strict editorial grid with bright moving parts. Layouts use hard lines, large type, geometric forms, and generous empty space.

The site intentionally avoids stock imagery, generic gradients, glass cards, and fake product counts. The graphics are built entirely with HTML and CSS.

## Colors

| Role | Value | Use |
| --- | --- | --- |
| Ink | `#151719` | Text, footer, primary actions |
| Paper | `#f3f0e8` | Main background |
| White | `#fffdf7` | Elevated light surfaces |
| Signature blue | `#3657db` | Main brand field and emphasis |
| Signal orange | `#ff5c39` | Markers, active details, energy |
| Acid | `#d5f36b` | Success, launches, small highlights |

Maintain strong contrast. Acid is an accent surface, not body text on paper.

## Typography

The brand uses system fonts so it loads immediately and remains private/offline-friendly:

- Arial/Helvetica for primary display and interface text.
- Georgia for human, editorial emphasis.
- Courier New for coordinates, metadata, and release labels.

## Mark

The Poller Apps mark is a rotated square containing three points. It represents an idea moving through three states: question, experiment, release.

Do not stretch, add effects, or place the mark on visually noisy imagery. Keep at least half the mark's width clear around it.

## Voice

Use short, direct language. Describe what exists and what it helps someone do.

Preferred:

```text
A private poker settlement tool that checks every shekel.
```

Avoid inflated language such as “revolutionary,” “world-class,” “cutting-edge,” or claims about projects that are not ready.
